The lab

The same panels as chapter 14's sandbox, wired to real kernels. Every switch here runs a command inside a container; every probe watches the far end while it knocks, and reports the rung that decided it. Nothing on this page is modelled, which means it can surprise you — and that is the only reason it exists.

This is a lab, and it is only safe because of where it is

evil-box attacks containers you started, on hardware you own, on bridges that go nowhere. It never starts unless you ask for it. This control server holds the Docker socket and has no authentication, so it is published to 127.0.0.1 only and refuses to start if that is changed. Everything here is provided as is, with no warranty — see the disclaimer and the MIT licence in the guide.
