What this page is

            

              The same panels as chapter 14's sandbox, wired to real kernels. Every switch
              here runs a command inside a container; every probe watches the far end while it
              knocks, and reports the rung that decided it. Nothing on this page is modelled,
              which means it can surprise you — and that is the only reason it exists.
            


            

              
This is a lab, and it is only safe because of where it is

              

                evil-box attacks containers you started, on hardware you own, on
                bridges that go nowhere. It never starts unless you ask for it. This control
                server holds the Docker socket and has no authentication, so it is published to
                127.0.0.1 only and refuses to start if that is changed. Everything
                here is provided as is, with no warranty — see the disclaimer and the MIT
                licence in the guide.

How to read the board

            

              The board is the five-rung ladder drawn as a place a packet travels through. It
              goes left to right along the rungs, and its height says whether it was wrapped
              while it went. Where it stops is the rung that decided the connection, and the
              five-segment strip under the drawing marks it.
            

            

              Drag to orbit, and press h — or reset view in the corner — to
              put the camera back.
            

            

              The canvas is decoration you can switch off. Every state the board shows is
              also in the readouts over it and in the packets tab, and the verdict goes to a live
              region, so nothing here is only available to somebody who can see it move. With
              prefers-reduced-motion set, the camera holds the final frame instead of
              flying to it and the words are identical.
            


            
How to read the flat drawing

            

              The height of the line is the point. Straight across the middle and it never
              left the tailnet. Bending up through the box in the centre and it is being relayed
              through DERP. Dipping into the red band and it crossed the public segment,
              where anyone on it can reach you. Run a probe and the shape changes to whatever
              really happened.
